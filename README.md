# AI 기반 대출 승인 여부 예측 프로젝트

## 1. 프로젝트 소개

본 프로젝트는 대출 신청자의 다양한 정보를 바탕으로 대출 승인 여부를 예측하는 머신러닝 기반 웹 애플리케이션입니다.

대출 신청자의 소득, 신용 이력, 대출 금액, 대출 기간, 부동산 지역 등의 데이터를 분석하고, 여러 머신러닝 알고리즘의 성능을 비교하여 최적의 예측 모델을 선정하였습니다.

또한 Streamlit을 활용하여 사용자가 직접 대출 신청 정보를 입력하고 예측 결과를 확인할 수 있는 웹 기반 프로토타입을 구현하였습니다.

### 프로젝트 목적

- 대출 신청 데이터의 탐색적 데이터 분석(EDA)
- 데이터 전처리 및 머신러닝 모델 학습
- 다양한 분류 알고리즘의 성능 비교
- 최적의 대출 승인 예측 모델 선정
- 웹 애플리케이션을 통한 예측 및 분석 결과 시각화

---

## 2. 주요 기능

본 프로젝트는 총 4개의 탭으로 구성되어 있습니다.

### ① 신청 정보 예측

- 신청자의 기본 정보 입력
- 소득 및 대출 관련 정보 입력
- 신용 이력 및 부동산 지역 선택
- 입력 정보를 기반으로 대출 승인 여부 예측
- 승인 및 거절 예측 결과 확인
- 승인 예측 확률 확인

### ② 데이터 탐색 및 인사이트

- 원본 데이터 미리보기
- 데이터 기본 정보 확인
- 변수별 결측치 현황 분석
- 대출 승인 및 거절 비율 시각화
- 변수 간 상관관계 Heatmap
- VIF를 활용한 다중공선성 확인
- 수치형 변수 분포 분석
- 범주형 변수별 승인 비율 분석

### ③ 머신러닝 분석

- 머신러닝 모델별 성능 비교
- 교차검증 결과 확인
- 최종 선정 모델의 성능 평가
- Accuracy, Precision, Recall, F1 Score, ROC-AUC 확인
- Confusion Matrix 시각화
- ROC Curve 시각화
- Permutation Importance를 활용한 변수 중요도 분석

### ④ 트러블슈팅

- 데이터 및 모델 파일 경로 관리
- 결측치 처리 문제
- 전처리 Pipeline 통합
- 모델별 공정한 성능 비교
- 예측 결과 및 확률 해석 시 유의사항

## 5. 데이터 전처리

모델 학습 전 데이터의 결측치 및 변수 유형을 고려하여 전처리를 진행하였습니다.

| 항목          | 처리 방법                  |
| ------------- | -------------------------- |
| 수치형 결측치 | 중앙값(Median) 대체        |
| 범주형 결측치 | 최빈값(Mode) 대체          |
| 수치형 변수   | StandardScaler 표준화      |
| 범주형 변수   | OneHotEncoder 인코딩       |
| 식별자 변수   | Loan_ID 제거               |
| 목표 변수     | Loan_Status를 0과 1로 변환 |

전처리 과정은 `ColumnTransformer`와 `Pipeline`을 활용하여 모델 학습 및 예측 과정에서 동일하게 적용되도록 구성하였습니다.

## 6. 머신러닝 모델

총 5개의 모델을 비교하였습니다.

| 모델                | 설명           |
| ------------------- | -------------- |
| DummyClassifier     | 단순 기준 모델 |
| Logistic Regression | 로지스틱 회귀  |
| Decision Tree       | 의사결정나무   |
| Random Forest       | 랜덤 포레스트  |
| Extra Trees         | 엑스트라 트리  |

### 모델 선정 기준

- 학습 데이터와 테스트 데이터를 80:20으로 분리
- `random_state=42` 적용
- Stratified K-Fold 5겹 교차검증
- 평균 F1 Score를 주요 모델 선정 기준으로 활용

### 모델별 교차검증 결과

| 모델                | Accuracy | F1 Score | ROC-AUC |
| ------------------- | -------: | -------: | ------: |
| Random Forest       |   0.7677 |   0.8441 |  0.7534 |
| DummyClassifier     |   0.6864 |   0.8140 |  0.5000 |
| Logistic Regression |   0.7290 |   0.8058 |  0.7263 |
| Extra Trees         |   0.7128 |   0.7973 |  0.7027 |
| Decision Tree       |   0.6109 |   0.6924 |  0.6555 |

교차검증 결과 Random Forest 모델의 평균 F1 Score가 가장 높아 최종 모델로 선정하였습니다.

### 최종 모델 테스트 결과

| 평가 지표 |   결과 |
| --------- | -----: |
| Accuracy  | 82.93% |
| Precision | 84.04% |
| Recall    | 92.94% |
| F1 Score  | 88.27% |
| ROC-AUC   | 79.72% |

※ 위 수치는 기존 분석 기록을 기준으로 작성한 결과이며, 최종 실행 환경에서 재검증이 필요합니다.

## 8. 실행 방법

### 1) 프로젝트 다운로드 및 폴더 이동

프로젝트 폴더를 다운로드한 후 터미널에서 해당 폴더로 이동합니다.

```bash
cd loan_approval_project
```

### 2) 가상환경 생성 및 실행 (선택 사항)

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

### 3) 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 4) 모델 파일 준비

`model/` 폴더에 다음 파일이 존재하는지 확인합니다.

```text
model/
├── model.pkl
└── model_meta.joblib
```

모델 파일이 없는 경우 `loan_approval.ipynb`를 실행하여 모델 학습 및 저장 과정을 먼저 수행해야 합니다.

### 5) Streamlit 실행

```bash
streamlit run app.py
```

실행 후 터미널에 표시되는 로컬 주소로 접속합니다.

일반적으로 다음 주소에서 확인할 수 있습니다.

```text
http://localhost:8501
```

## 10. 프로젝트 한계 및 향후 개선 방향

### 프로젝트 한계

- 제한된 공개 데이터셋을 기반으로 모델을 학습하였으므로 실제 금융 환경에 일반화하는 데 한계가 있습니다.
- 승인 데이터와 거절 데이터의 비율에 차이가 존재합니다.
- 모델의 예측 결과가 실제 금융기관의 대출 승인 결과와 일치한다고 보장할 수 없습니다.
- 변수 중요도는 예측에 대한 상대적 기여도를 나타내며 인과관계를 의미하지 않습니다.

### 향후 개선 방향

- 더 다양한 대출 신청 데이터 확보
- 외부 데이터 기반 모델 성능 검증
- 하이퍼파라미터 최적화를 통한 예측 성능 개선
- 예측 결과에 대한 설명 기능 강화
- 집단별 예측 편향 및 공정성 검토
- 모델 버전 관리 및 예측 결과 모니터링 기능 추가

## 11. 유의사항

본 프로젝트는 머신러닝 학습 및 데이터 분석을 목적으로 제작한 교육용 프로토타입입니다.

모델이 출력하는 대출 승인 여부와 예측 확률은 학습 데이터의 패턴을 기반으로 산출된 추정 결과이며, 실제 금융기관의 대출 심사 결과나 승인 여부를 보장하지 않습니다.

실제 금융 서비스에 적용하기 위해서는 추가적인 데이터 검증, 모델 성능 검토, 개인정보 보호 및 관련 법·제도에 대한 검토가 필요합니다.
